# /test-scenario-doc — Human QA Scenario Doc

Generate a self-contained interactive HTML test-scenario / QA checklist for a **human** to run a manual test pass. **On-demand only** — invoke when the human wants a manual verification doc. It is NOT auto-generated by the team workflow.

## Usage

```
/test-scenario-doc [feature / PR / area]
```

## What it does

1. Invoke the `test-scenario-doc` skill (the engine: template + authoring guide).
2. Derive scenarios from the named feature / PR / diff — or the current conversation if the work happened here. If scope is fuzzy, ask what areas matter and what "done" looks like first.
3. Copy `skills/test-scenario-doc/assets/test-scenarios-template.html`, fill ONLY the `<script id="ts-config">` block (META / GROUPS / SCENARIOS), and save the `.html`.
   - Default destination in a harness repo: `_docs/qa/<topic>-test-scenarios.html` (or cwd / a path the user gives).
4. Hand over the file path; the human opens it (`file://…`), runs the pass, and shares the image-embedded result HTML.

## Position in the testing stack

Human final-acceptance layer: **vitest** (unit) → **e2e / agentic-testing** (automated) → **/test-scenario-doc (human manual QA)**. Complements `agentic-testing` (agent verifies goals) with a human-run checklist. Human-requested, not workflow-wired.
